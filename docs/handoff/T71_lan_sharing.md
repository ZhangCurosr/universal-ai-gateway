# T71 网页端局域网共享（已批准，已完成）

- **类型**：规格 + 实现。2026-11-14 用户批准 §7 的全部建议（「全部按建议」）。
- **前置**：T55（配置重载，`DONE`）、T49（管理 Web UI，`DONE`）。
- **约束**：不改 `internal/core` 与 `internal/protocol` 的导出 API；不改分层规则；不加依赖。管理面仍然只监听本机（DEP-03 不变），本卡只共享**数据面**。

## 1. 要解决的问题

网关的数据面缺省监听 `0.0.0.0:8080`，局域网里的其他设备技术上已经能连，但用户在网页上看不到：

- 现在是不是对局域网开放；
- 别的设备应该填什么地址（本机有几块网卡、哪个是局域网 IP）；
- Windows 防火墙要不要放行、怎么放行；
- 另一台设备上的 Claude Code、OpenAI SDK、MCP 具体怎么配。

想关闭或打开局域网共享，只能手工改 `gateway.yaml` 的 `server.data_listen` 再重载。

## 2. 页面：「局域网共享」

管理页面导航新增「局域网共享」（`#/share`），内容自上而下：

1. **状态卡片**
   - 「已对局域网开放」（绿色）或「只允许本机访问」（灰色）。判断依据是数据面的实际监听地址：主机部分是 `0.0.0.0`、`::` 或某个局域网 IP 即为开放；`127.0.0.1`、`::1`、`localhost` 即为仅本机。
   - 开关按钮「开启局域网共享」/「关闭局域网共享」（见 §3），点击前二次确认，说明会短暂重启数据面（已有连接排空后切换，约 1–2 秒）。
   - 开启时显示明文 HTTP 的风险提示（同网段设备可以嗅探 Token；不可信网络请用 HTTPS 反向代理，DEPLOYMENT.md §2.2）。
2. **访问地址**：本机每个可用的局域网 IPv4 地址各一行 `http://<IP>:<端口>`，带「复制」按钮；排除回环、链路本地（169.254.x.x）、未启用的网卡，标出网卡名（如「WLAN」「以太网」）。没有局域网地址时提示「本机没有连接到局域网」。
3. **防火墙**（只在网关运行于 Windows 时显示）：说明需要放行入站 TCP 端口，给出可复制的命令（只放行「专用网络」）：
   `New-NetFirewallRule -DisplayName "AI Gateway" -Direction Inbound -Protocol TCP -LocalPort <端口> -Action Allow -Profile Private`
   网关**不**自动修改防火墙（系统安全设置由用户自己改）。Linux 显示 ufw 示例。
4. **在另一台设备上使用**：选择地址后，生成以下配置片段（`<Token>` 是占位符），每段带「复制」按钮：
   - 环境变量：`UAIG_URL=http://<IP>:<端口>`、`UAIG_TOKEN=<Token>`；
   - Claude Code：`ANTHROPIC_BASE_URL`、`ANTHROPIC_AUTH_TOKEN`；
   - OpenAI SDK：`base_url="http://<IP>:<端口>/v1"`；
   - MCP：`claude mcp add --transport http uaig http://<IP>:<端口>/mcp --header "Authorization: Bearer <Token>"`；
   - 一行指向 `docs/AI_QUICKSTART.md` 的说明。
   - 按钮「为这台设备创建 Token」：跳到「客户端」页的新建表单并预填名称（如 `lan-device`），Token 仍然只在创建时显示一次。本页不显示、不保存任何 Token。

## 3. 开关的实现：网页修改配置文件

| 编号 | 规则 |
|:--|:--|
| LAN-01 | `GET /admin/api/share`：`{"listen": "0.0.0.0:8080", "port": 8080, "lan_open": true, "addresses": [{"ip": "192.168.1.23", "interface": "WLAN", "url": "http://192.168.1.23:8080"}], "os": "windows", "config_writable": true, "url_template": "http://<IP>:8080"}`（地址由服务端拼好，页面脚本中不出现绝对 URL，UI 静态规则）。地址来自 `net.Interfaces()`，只取启用的、非回环、非链路本地的 IPv4，按网段排序（192.168/16、172.16/12、10/8 在前，其他如 VPN 的 100.64/10 在后；第一项是页面的缺省选择）；`lan_open` 按 §2 第 1 条判断。`config_writable` 为 false 时（没有配置文件路径，或文件不可写）页面隐藏开关，提示手工修改 |
| LAN-02 | `POST /admin/api/share`，请求体 `{"lan_open": true|false}`（缺少 → 400；不能修改配置文件 → 409）：把配置文件中的 `server.data_listen` 改为 `0.0.0.0:<端口>` 或 `127.0.0.1:<端口>`（端口不变），然后按 HR 规则重载（监听地址变化 → 进程内重启），成功时返回 `{"changed": true, "listen", "reload": <ADM-18 的响应>}`，状态码同重载（重启为 202）。运行中的监听地址已经是目标状态时返回 200 `{"changed": false}`，不写文件；文件已是目标值但还没生效时直接重载。同一端口先绑定新地址再关闭旧地址（§2.3）：Windows 支持；不支持的系统上预检失败，按 LAN-03 恢复文件并返回 422 |
| LAN-03 | 写配置文件：用 `yaml.v3` 定位字段，只替换该值的原文（不重新序列化整个文件），**保留注释与其他内容的原样**；文件里没有 `server.data_listen` 时在 `server:` 下追加（没有 `server:` 就新建）。写入前先用 `config.Parse` 校验新内容；先备份为 `<文件名>.bak`（覆盖上一份备份），再写临时文件并 `rename`。重载失败时把备份写回并返回错误（网关继续用原来的监听地址） |
| LAN-04 | 每次修改记 Info 日志 `config edited by admin`（字段名、旧值、新值），并出现在重载记录中（ADM-19） |
| LAN-05 | 修改配置文件的代码放在 `internal/config`（`yaml.v3` 只允许在这里，spec/01 §4）：`config.SetScalar(data, keys, value)`（只替换这一处文本）、`config.EditFile(path, keys, value)`（校验、备份、原子写入）、`config.WriteFileAtomic`，供本卡与后续「网页管理池与服务」复用；`admin` 通过 `Deps` 注入的函数调用，不直接接触文件路径 |
| LAN-06 | 管理面本身不受影响：仍然只监听本机（CFG-02、DEP-03）。页面上说明：其他设备只能用网关的 AI 能力，不能打开管理页面 |

## 5. 测试

- `config.SetField`：保留注释、字段不存在时追加、`server:` 不存在时新建、校验失败不写文件、备份与原子替换。
- `GET share`：监听地址的各种形式（`0.0.0.0`、`::`、`127.0.0.1`、`localhost`、具体 IP）→ `lan_open`；地址过滤。
- `POST share`：开 → 关 → 开，文件内容与重载模式（restart）；值相同不写；配置文件不可写 → 409；重载失败回滚文件。
- 端到端：进程内重启后数据面在新地址上可用，管理面地址不变。
- UI：导航存在、片段中只有 `<Token>` 占位符、文案中英文齐全。

## 6. 实测（验收）

1. 本机网关开启局域网共享，用本机的局域网 IP（不是 127.0.0.1）访问 `/v1/models` 成功；关闭后同一地址连接被拒绝，`127.0.0.1` 仍然可用。
2. `gateway.yaml` 中只有 `data_listen` 那一行变化，注释保留；`.bak` 是修改前的内容。
3. 页面列出的地址与 `ipconfig` 一致；防火墙命令可以复制。

## 7. 决策（已批准）

| # | 问题 | 选项 | 建议 |
|:-:|:--|:--|:--|
| 1 | 开关怎么生效 | A. 网页直接改 `gateway.yaml` 并重载（保留注释、留备份）；B. 只显示状态和说明，开关仍然手工改文件 | **A**：这是用户要的「在网页上操作」；改的仍然是配置文件，手工编辑与网页编辑不冲突 |
| 2 | 是否自动配置 Windows 防火墙 | A. 不自动，只给命令；B. 网关调用 `netsh` 自动放行 | **A**：修改系统安全设置应由用户自己做；网关通常也没有管理员权限 |
| 3 | 页面是否直接创建 Token | A. 跳转到「客户端」页预填名称；B. 在本页创建并显示 | **A**：Token 只在一个地方创建、只显示一次，规则不分散 |
| 4 | 是否顺带做「网页管理池与服务」 | A. 不在本卡做，单独一张卡（T72），复用 LAN-05 的写配置能力；B. 一起做 | **A**：池与服务的表单（协议、地址、价格、额度、告警……）比开关复杂得多，分开审、分开提交 |
| 5 | 关闭共享后改成什么地址 | A. `127.0.0.1:<端口>`；B. 让用户选一块网卡只在它上面监听 | **A**：「开 / 关」两个状态最好理解；只在某块网卡上监听的需求很少，仍可手工改文件 |
